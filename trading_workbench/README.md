# Trading Workbench

Personal trading workspace for a Raspberry Pi 4 running 64-bit Home Assistant OS.
Open it through Home Assistant's authenticated ingress UI.

Repository: https://github.com/jokestorm/trading-workbench
A tagged ARM64 image must be published before installation.

See [installation and release instructions](DOCS.md) and [the staged plan](../docs/home-assistant-plan.md).
